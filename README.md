# Ритм

[Открыть демо](https://impecabllo.github.io/ritm-todo/) · Список задач на React и TypeScript.

Добавьте задачу кнопкой или клавишей **Enter**, нажмите на чекбокс или текст, чтобы изменить статус, и удалите ненужное через корзину. Последнее удаление можно отменить. Фильтры и индикатор прогресса обновляются сразу.

При первом открытии в списке есть пять примеров. После изменений список сохраняется в `localStorage`, даже если удалить все задачи. Изменения видны в других открытых вкладках того же сайта. Сервер и аккаунт не нужны: задачи остаются в текущем браузере, очистка данных сайта удаляет список.

## Запуск

Требуется Node.js 24 и npm.

```sh
npm ci
npm run dev
```

Проверки и тестирование собранной версии:

```sh
npm run lint
npm run format:check
npm run build
npx playwright install chromium
npm test
```

## Как устроено

- `src/app` — каркас приложения, цвета, типографика и адаптивная сетка.
- `src/features/tasks/model` — тип задачи, фильтрация, действия и чтение/запись версионированного ключа хранилища.
- `src/features/tasks/ui` — форма, фильтры, строки задач и карточка прогресса. Чекбоксы используют Radix UI, иконки — Lucide.
- `tests` — браузерные сценарии для добавления, выполнения, удаления, сохранения, отмены удаления, фильтров, ошибок хранения и доступности.

GitHub Actions проверяет сборку и тесты перед публикацией на GitHub Pages. В интерфейсе нет внешних запросов для загрузки шрифтов: Inter и Manrope включены в сборку. Лицензии шрифтов лежат в `public/licenses`.

Для реализации, ревью и тестов использован **OpenAI Codex**. Визуальный ориентир для списка и счётчиков — [Sprint Task Checklist на 21st.dev](https://21st.dev/%40cnippet-dev/components/sprint-task-checklist); оформление «Ритма» и код приложения сделаны для этого проекта.
